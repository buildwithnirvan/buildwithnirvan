## About Me

I'm a Data Analyst and aspiring AI/ML Engineer who enjoys turning raw, messy data into dashboards people actually use — and turning ideas into working intelligent systems. My work sits across **data analytics, machine learning, artificial intelligence, and computer vision**, with a focus on building practical, end-to-end applications rather than isolated notebooks.
